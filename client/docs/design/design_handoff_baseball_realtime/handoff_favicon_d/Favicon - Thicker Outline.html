Favicon: making the diamond readable at 16px

A browser tab draws the favicon at 16px, so 1 unit of the 64-unit icon is only ¼ px. The current 2.5 stroke ends up about 0.6px wide, thinner than a pixel, so it blurs into a faint ring. Adding 1 unit only adds ¼ px, which is why it looked the same. These versions size the stroke for the tab instead.
